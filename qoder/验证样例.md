# 验证样例（可逐步执行）

初始数据：`content/` 下 5 篇 Markdown 笔记，按二级标题切成 **28 个切片**，切片标题拼进正文后
写入 seekdb，并在 `body` 上建 `FULLTEXT INDEX ft_body (body) WITH PARSER ik` 全文索引。

## 0. 环境

- Node.js ≥ 18（无需 `npm install`：自检与服务只用内置模块）
- 可选：要重建索引才需要 `npm install`（拉 `@oceanbase/seekdb-node` 嵌入式 seekdb）与 Python 无关

## 1. 自检模式（数秒结束，退出码 0）

```bash
cd qoder
node main.mjs          # 等价 npm run selfcheck / python 无法使用时同样可用
```

预期输出（机器可判读的是最后一行与退出码）：

```
StudyLens selfcheck
  ok   server up — chunks=28 docs=5
  ok   search "中文分词器怎么选" — 4 hits, 0.761 ms, engine=seekdb, top=建表与全文索引
  ok   search "倒排索引" — 8 hits, 0.387 ms, engine=bm25, top=倒排索引的基本结构
  ok   search "切片策略 语义边界" — 4 hits, 0.666 ms, engine=seekdb, top=切片策略
  ok   search "BM25 相关度打分" — 6 hits, 0.798 ms, engine=seekdb, top=相关度打分：BM25 与 TF-IDF
  ok   page served — id="q" 存在
  ok   index export — 28 chunks / 5 docs

SELFCHECK PASS
```

`echo $?` → `0`。自检内部会随机挑一个端口起服务、打 4 个检索请求、再关掉，**不依赖外网**。

没有 node 的环境用纯 Python 版，检查内容与上面一一对应（读同一份索引复算 BM25）：

```bash
python main.py         # StudyLens selfcheck (python) ... SELFCHECK PASS，退出码 0
```

## 2. 服务模式（给浏览器）

```bash
node main.mjs --serve      # 或 npm start，默认 3000 端口
```

浏览器打开 <http://127.0.0.1:3000>：搜索框已预填「中文分词器怎么选」，显示命中 4 条、耗时 0.761 ms；
在框里输入任意关键词（例如「倒排索引」），**输入即搜**，结果换成 8 条、按 BM25 降序。

## 3. HTTP 接口（不打开浏览器也能验证主要功能）

```bash
curl -s localhost:3000/api/health
# {"ok":true,"engine":"seekdb (FULLTEXT + IK parser, BM25)","chunks":28,"docs":5,"presets":12,"entry":"web/index.html"}

curl -s "localhost:3000/api/search?q=%E5%80%92%E6%8E%92%E7%B4%A2%E5%BC%95"
# {"q":"倒排索引","engine":"bm25","source":"index-export","latencyMs":0.39,"total":8,
#  "hits":[{"doc":"全文索引与中文分词","heading":"倒排索引的基本结构","score":10.345,...},...]}
```

| 输入 | 期望 | 判据 |
|---|---|---|
| `GET /api/health` | `ok:true`、`chunks:28`、`docs:5` | 索引已就绪 |
| `/api/search?q=中文分词器怎么选` | `total:4`、`engine:"seekdb"`、`latencyMs≈0.76` | 走 seekdb 实测导出 |
| `/api/search?q=倒排索引` | `total:8`、`engine:"bm25"` | 同一索引上的 BM25 重排 |
| `GET /` | 200，含搜索框与结果卡片 | 站点可交互 |

完整机器可读结果见 [`docs/smoke_results.json`](docs/smoke_results.json)（本次运行 health + 5 组查询 + 页面探针的原始 JSON）。

## 4. seekdb 发挥作用的证据链

| 步骤 | 命令 / 文件 | 可见证据 |
|---|---|---|
| 建表与全文索引 | `src/db.mjs` | `FULLTEXT INDEX ft_body (body) WITH PARSER ik` |
| 切片入库（幂等） | `node src/ingest.mjs` | 输出「写入 28 个切片」+ 按主题统计；`(doc, heading)` 唯一键 + `ON DUPLICATE KEY UPDATE` |
| 检索取 BM25 | `node src/search.mjs "倒排索引 词项"` | 打印 doc / heading / score，分数由 `MATCH(body) AGAINST(...)` 返回 |
| 导出到站点 | `node src/search.mjs --export` | 写 `web/data/index.json`：12 组查询的命中与**单次查询耗时**（0.6–1.6 ms） |

重建索引（可选，需要 seekdb 运行时）：

```bash
npm install
node src/ingest.mjs
node src/search.mjs --export
```
